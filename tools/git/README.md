# 🛠️ مرجع أوامر Git الأساسية

هذا المجلد مخصص لأدوات Git وشروحاته. في هذا الملف، جمعنا لك أهم الأوامر التي ستحتاجها كطالب للتعامل مع مشاريعك على GitHub.

## 1. إعداد Git لأول مرة (Configuration)

قبل البدء، يجب أن تخبر Git بمن أنت:

```bash
git config --global user.name "اسمك هنا"
git config --global user.email "بريدك_الإلكتروني@example.com"
```

## 2. إنشاء مستودع جديد (Initialization)

لتحويل مجلد عادي إلى مستودع Git:

```bash
git init
```

## 3. إضافة الملفات (Staging)

لإضافة ملف معين:

```bash
git add اسم_الملف
```

لإضافة جميع الملفات والتعديلات دفعة واحدة:

```bash
git add .
```

## 4. حفظ التعديلات (Committing)

لحفظ التعديلات التي قمت بإضافتها مع رسالة توضيحية:

```bash
git commit -m "رسالة تشرح ما قمت بتعديله"
```

## 5. رفع التعديلات إلى GitHub (Pushing)

لرفع التعديلات إلى المستودع البعيد (Remote):

```bash
git push origin main
```

_(ملاحظة: استبدل `main` باسم الفرع الخاص بك إذا كان مختلفاً)._

## 6. جلب التحديثات (Pulling)

لجلب آخر التحديثات من المستودع البعيد إلى جهازك:

```bash
git pull origin main
```

## 7. التحقق من الحالة (Status)

لمعرفة الملفات التي تم تعديلها أو إضافتها:

```bash
git status
```

---

💡 **نصيحة:** يمكنك وضع ملف تثبيت برنامج Git في هذا المجلد ليكون متاحاً للطلاب الذين لم يقوموا بتثبيته بعد.
